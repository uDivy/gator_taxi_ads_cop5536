How to Run the Program
There are two ways to run the #Gator Taxi program:

Method 1: Using Makefile
To run the program using the Makefile, follow these steps:

Open a terminal or command prompt window and navigate to the directory where the program files are stored.
Type `make run FILE=<input_filename>` and press Enter. Replace `<input_filename>` with the name of the file that contains the input data for the taxi ride.
The program will read the input data from the file and output the fare to the "output_file.txt".

Method 2: Without Using Makefile
To run the program without using the Makefile, follow these steps:

Open a terminal or command prompt window and navigate to the directory where the program files are stored.
Type `python3 gatorTaxi.py <input_filename>` and press Enter. Replace `<input_filename>` with the name of the file that contains the input data for the taxi ride.
The program will read the input data from the file and output the fare to the "output_file.txt".
